# Supply Chain Performance & Fulfillment Analytics
## Overview
Interactive Excel dashboard designed to monitor supply chain performance and fulfillment KPIs.
## Tools Used
- Microsoft Excel
- Power Query
- PivotTables
- Pivot Charts
- Hyperlink
## Dashboard Features
- Revenue Analysis
- Profit Analysis
- Order Performance Tracking
- Fulfillment Rate Analysis
- Supplier Performance Analysis
- Category Performance Monitoring
## Key Insights
- Monitored fulfillment and operational KPIs.
- Evaluated supplier and category performance.
- Identified trends affecting supply chain efficiency.
